# Aula 2 - Banco de Dados

## Descrição
Este trabalho tem como objetivo aplicar conceitos de Álgebra Relacional e SQL, conforme orientações em sala de aula.

## Estrutura do repositório
- script.sql → criação do banco e tabelas
- consultas.sql → consultas em SQL
- relatorio.pdf → expressões em Álgebra Relacional
- prints/ → evidências da execução no DBeaver
